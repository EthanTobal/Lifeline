# LifeLine Demo Policy Corpus

These files define fictional insurance examples created for the LifeLine hackathon.

## Important
These are **not actual Lincoln Financial policies, quotes, premiums, guarantees, underwriting rules, or recommendations**. Product names, coverage examples, and pricing examples in this folder are simulated for demonstration purposes.

The examples are designed to align at a high level with the Lincoln Financial educational material used by LifeLine:
- Term insurance: limited/defined coverage period, generally lower cost, no cash-value growth.
- Indexed universal life: flexible characteristics and potential cash-value growth linked to an index.
- Variable universal life: flexible characteristics with cash value that can fluctuate based on investment options.

LifeLine should use these files only to demonstrate product comparison and matching logic after producing an illustrative needs assessment.

## Demo catalog
- LifeLine Term 20
- LifeLine Term 30
- LifeLine Indexed Protection
- LifeLine Variable Protection

## Application rule
Never present a demo policy as an actual Lincoln Financial product. The UI should visibly label all entries as `Hackathon Demo / Fictional Product`.

LifeLine should explain tradeoffs rather than state that a customer should purchase a particular product.
