OpenRouter settings

This is a demo. Your key is stored only in this browser. Real apps should call the API from a secure server, never the browser.

Enter an OpenRouter model ID in provider/model format. Choose a model that supports tools for memories, documents and embeds. Leave the API key empty to use the demo.

Use a model with tools, such as google/gemini-3.8-flash. Speech playback is configured below.

Automatic switches to microphone audio if browser speech fails. Pause briefly after speaking to send your turn. Microphone access requires HTTPS or localhost.

Microphone audio uses google/gemini-3.8-flash by default to transcribe speech. You can choose another OpenRouter model with audio input and text output. Your voice model still answers questions and creates documents.

Automatic uses your OpenRouter key for speech in voice mode and Read aloud. Without a key, it uses installed browser voices.

The default Microsoft speech model uses en-US-Harper:MAI-Voice-2.1-Flash. Voice IDs must match the speech model.
